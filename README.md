## Project Overview

This project contains the solutions for the Python Programming Assessment: Numbers & Basic Logic.

The assessment consists of two functions:

### 1. even_or_odd(n)

- Checks whether a given number is even or odd.
- Returns **"Even"** if the number is divisible by 2.
- Returns **"Odd"** otherwise.

### 2. add_all(numbers)

- Calculates the total sum of all numbers in a list.
- Uses a **for loop** and an **accumulator variable** to compute the result.

## Approach

- Used Python functions to solve each problem.
- Implemented conditional statements (`if-else`) for checking even and odd numbers.
- Used a `for` loop to iterate through the list and calculate the total sum.
- Kept the code clean, simple, and easy to understand.
